# 石油勘探开发智能化地图

石油勘探开发智能化地图，《可视化导论》课程网页项目。

**在线访问（GitHub Pages）：<https://could-yun.github.io/petro-ai-atlas/>**

本地查看：在项目根目录运行 `python -m http.server 8765`，再打开 `http://127.0.0.1:8765/`（也可以直接双击 `index.html`）。

网站收录教师数据中的 **13 个作业环节、61 个可智能化场景**，每个场景都可按环节浏览、按 AI 方法反查，并提供“当前做法—AI 介入点—数据清单—难度与参考方向”四段式详情。

其中 **9 个原创案例（地质勘察 4 个，物探 5 个）** 带完整的专业背景、案例流程与可运行演示；测井环节保留教师原版的**测井曲线智能分层**示范案例。其余场景显示“正在开发中”，可按原版协议上传案例。

| 环节 | 案例 | 实际执行的教学模型 | 主要图形 |
| --- | --- | --- | --- |

## 使用

直接打开根目录 `index.html`；或通过任意静态网页服务访问。全部页面使用普通脚本，无构建依赖、后端、CDN、在线模型服务或 API 密钥。

每个案例的结构与教师示范案例“测井曲线智能分层”一致：**专业背景**先给出任务类型、数据门槛、收益、难度四项速判，再分“当前做法与问题 / AI 能做什么 / 你需要准备什么（可勾选清单）/ 技术难度与参考方向”四段；**案例流程**以一个具体工区为例，列出项目规模、五个落地步骤（每步配一张示意图，画出这一步的做法与常见陷阱）、验收指标和常见失败原因；**可运行示范**支持参数重算、固定种子、换样本、图像位置读取、结果表与 JSON 导出。验收指标是立项目标，不是实测结果；示范中的数值来自合成数据。

## 上一轮修订的主要变化

- 首页保留 13 阶段总览；任务路线按“区域线索、构造解释、储层评价”组织案例，展示每项输出怎样帮助回答业务问题。独立合成案例之间没有伪造同一工区的数据流转。
- 9 个案例均增加同一测试数据上的传统基线对照；分数由实际计算得到，允许相同或低于基线。
- 5 档噪声实验固定测试种子和第二参数，分别重算基线与模型，观察性能随干扰变化；连线只帮助阅读五个条件，不提供置信区间。
- 实验记录保存当前参数、种子、指标、扫描结果和观察笔记。相同案例的两条记录可并排比较，并提示种子是否一致；可导出 JSON。
- 光谱示意与模型使用同一组离散波段数据；概念图、流程图、数据图统一核查标注、单位、图例和色标。振幅与概率分面，方向玫瑰图以面积表达占比，去噪输入/输出/残差使用统一色标。

所有数据均为程序生成的教学合成数据。训练与评价样本按各演示说明分离。网页展示的精度、误差及信噪比实时计算，不代表真实工区效果。大型深度网络作为参考方向讨论，未被冒称为实际部署模型。

## 独立案例包与教师兼容

`downloads/` 中一个案例对应一个 ZIP，按“地质勘察-小类别”或“物探-小类别”命名；没有多个案例打成一个提交包。

1. 解压单个 ZIP。
2. 教师原版门户或本网站点击“添加案例”。
3. 选择或拖入包含 `case.json` 的整个案例文件夹。
4. 校验后点击“校验并添加”。

与教师 `firstbreak-pick-case` 相同的 `case.json + demo/index.html` 格式；`assets/core/case-upload.js`、`case-demo-host.js`、`registry.js` 未修改。导入案例沿用原版 localStorage，只保存在当前浏览器。重复 ID 由原版校验器拒绝；可为导入副本填写新的唯一 ID，或在未修改的教师框架中导入。

完整的接入说明（上传案例包的四步、两种示范写法、写插件的三步、契约字段、工具箱、常见错误与删除方式）见站内“接入指南”页与 `docs/如何添加新案例.md`，内容与教师原版《如何添加新案例》一致，只把文件名换成本站结构（`assets/site.js` 对应教师的 `shell.js`，校验表格位于“案例实验室”页底部的案例校验控制台）。插件模板 `assets/cases/_template.case.js` / `_template.case.json` 取自教师框架。

`teacher/` 保留附件中未修改的原版门户与原版初至波案例，便于直接对照。主站的 `assets/cases/welllog-layer.*.js` 是教师测井示范案例的原样副本。9 个原创包已逐个在未修改的教师门户中通过文件夹选择、校验、添加和演示运行；教师初至波示例也已导入新门户运行。

## 开发与验证

这些脚本只用于生成静态文件和校验，不属于后端：

```text
python tools/build_cases.py
node tools/generate_theory.cjs
python tools/build_cases.py
node tools/check_models.cjs
node tools/check_contract.cjs
node tools/check_figures.cjs
```

`check_models.cjs` 检查 9 个模型的默认值、确定性、噪声上下限和第二参数极端值，并断言默认参数下每个模型优于其基线、初至波 5 档噪声扫描随噪声下降；`check_contract.cjs` 使用原版校验器检查清单、场景标题、注册与文件哈希；`check_figures.cjs` 检查概念状态、流程图与结果图的绘图契约。浏览器核查包括独立演示、噪声扫描、流程切换、实验记录及教师框架导入。按任务范围以桌面 Web 为目标。
